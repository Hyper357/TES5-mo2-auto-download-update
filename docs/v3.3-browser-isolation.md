# v3.3 Browser Isolation

## 目标

Nexus 自动化浏览器必须与用户日常 Edge/Chrome 完全隔离。项目不应给用户正在工作的浏览器开启远程调试，也不应仅凭“9222 能连接”就默认那个浏览器可以被 Pi Agent 控制。

## 架构

```text
用户日常 Edge
  └─ 正常启动，无 CDP，无 Puppeteer 控制

TES5-MO2 Automation Browser
  ├─ 独立 user-data-dir
  ├─ CDP 127.0.0.1:9222
  ├─ 独立 Nexus 登录态
  ├─ profile marker
  └─ sentinel target
       └─ Pi Agent / Puppeteer 只允许连接这里
```

默认 Profile：

```text
%LOCALAPPDATA%\TES5-MO2-AutoUpdate\browser-profile
```

可使用环境变量覆盖：

```text
MO2_AUTOMATION_PROFILE
MO2_AUTOMATION_BROWSER
MO2_CHROME_FOR_TESTING
MO2_CDP_PORT
MO2_BROWSER_ROOT
```

## 命令

### 首次/日常启动

```powershell
npm run browser:start
```

浏览器查找顺序：

1. `MO2_AUTOMATION_BROWSER`；
2. `MO2_CHROME_FOR_TESTING`；
3. 项目 `.runtime/browser` 已安装的 Chrome for Testing；
4. 系统 Chrome；
5. 都没有时自动下载官方 Chrome for Testing stable win64。

首次安装也可显式执行：

```powershell
npm run browser:install
```

### 查看状态

```powershell
npm run browser:status
```

正常必须看到：

```json
{
  "state": "MANAGED",
  "managed": true,
  "cdp": true
}
```

### 停止

```powershell
npm run browser:stop
```

`browser:stop` 只允许关闭带有效项目 sentinel 的浏览器；如果 9222 属于其他浏览器，会拒绝关闭，防止误杀用户工作窗口。

## Profile 身份证明

项目不是只检查 CDP 端口，而是使用两层证明：

1. 独立 Profile 目录中的 `.tes5-mo2-automation.json` 随机 token；
2. 浏览器中保留的 sentinel target，其 URL 携带同一个 token。

只有 marker + sentinel 一致，状态才是 `MANAGED`。

若端口存在但证据不匹配：

```text
BROWSER_PROFILE_MISMATCH
```

该错误不可自动重试，也不可接管现有浏览器。

## 用户遇到 Edge“是否允许远程调试”弹窗时

这通常表示以前的普通 Edge 实例仍以远程调试模式启动。

迁移步骤：

1. 关闭当前带“由自动测试软件控制/远程调试”提示的 Edge 实例；
2. 从普通 Edge 快捷方式重新打开日常 Edge，不添加任何 `--remote-debugging-port`；
3. 在项目目录执行 `npm run browser:start`；
4. 在新出现的独立自动化浏览器中登录 Nexus 一次；
5. 日后让该自动化浏览器最小化留在后台即可。

不要在 Edge 设置中全局关闭开发者功能来“消掉弹窗”，因为那会破坏自动化能力；正确方案是把调试能力限制在独立浏览器实例。

## 与 v3.2 Diagnostics 的关系

`diagnose.js` 现在包含：

```text
AUTOMATION_BROWSER
BROWSER_ISOLATION
```

真实 `--go` 前的 Preflight 必须看到 `AUTOMATION_BROWSER=OK` 且 `BROWSER_ISOLATION=OK`。

如果浏览器未启动：

```text
CDP_UNAVAILABLE
```

运行：

```powershell
npm run browser:start
```

如果 9222 被错误浏览器占用：

```text
BROWSER_PROFILE_MISMATCH
```

先关闭那个远程调试浏览器，再启动项目专用浏览器。禁止 Pi Agent 尝试接管或关闭不受管理的浏览器。
