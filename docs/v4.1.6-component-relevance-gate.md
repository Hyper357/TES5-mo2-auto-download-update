# v4.1.6 Component Relevance Gate

## Incident
A real v4.1.5 run found 60 `UPDATE_CONFIRMED` items but released zero downloads. Component Discovery produced 1,443 tasks and moved 242 items to Review Center.

The root cause is over-blocking rather than missing browser access:

1. Nexus **Mods requiring this file** is reverse-dependency evidence. An uninstalled downstream mod is not a companion that the updated Main must download.
2. Explicitly optional, uninstalled companions are evidence worth showing, but are not automatically required.
3. Translation closure previously demanded an explicit `TRANSLATION NONE` registry row even when complete discovery found zero translation candidates. That makes every Main require manual bookkeeping.

## Relevance policy
Discovery still records all candidates, but only **blocking candidates** participate in the completeness gate.

Blocking by default:
- forward Nexus Requirements / explicit required hints;
- installed/local component evidence;
- learned relation-registry candidates;
- candidates matching active installed context;
- same-page components that are not explicitly optional;
- patch/hotfix candidates whose active compatibility counterpart is enabled.

Non-blocking evidence:
- reverse-requirement candidates with no active/local match;
- explicitly optional candidates that are not already installed/selected;
- weak Description candidates with neither required nor installed-context evidence.

A non-blocking candidate is not silently classified as REQUIRED or NOT_APPLICABLE. It remains visible in discovery output/Review evidence with a relevance disposition, but it does not hold an otherwise safe Main.

## Translation rule
Complete discovery with zero translation candidates now proves translation closure for that Main. If a Chinese translation candidate is discovered, installed, related, or explicitly required, it remains subject to exact closure and cannot be skipped implicitly.

## Safety boundary
This change does not weaken Update Eligibility, Main/Variant selection, exact file identity, forward required dependencies, installed companion protection, queue idempotency, MO2 UI Guard, or VERIFIED semantics.
